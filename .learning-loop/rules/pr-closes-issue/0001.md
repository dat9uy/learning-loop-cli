---
name: pr-closes-issue
description: Close an issue only through a pull request that references it.
---

Closing an issue must happen through a pull request that references it:

- create a feature branch for the work,
- open a pull request that references the issue it resolves, and
- close the issue only after the pull request is merged.

Reason: every closed issue stays traceable to a reviewed, merged change instead of an unreviewed direct commit.
