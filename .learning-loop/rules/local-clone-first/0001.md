---
name: local-clone-first
description: Explore an external codebase from a local clone, not the GitHub API.
---

Exploring an external codebase must start from a local clone:

- search the local machine for an existing copy of the repository first,
- clone the repository when no local copy exists, and
- read the code from the local clone rather than fetching files through the GitHub API.

Reason: a local clone keeps exploration fast and offline-capable, and avoids hammering the GitHub API with per-file requests.
